# Arborist Practice Questions

A static Jekyll/GitHub Pages learning site organized by subject domain.

## Content structure

- `botany/` — tree biology, identification, section quiz
- `soil-and-nutrition/` — soil science, analysis, water, nutrition, fertilization, section quiz
- `disorders-and-disturbances/` — abiotic disorders, pests/pathogens, diagnostics, PHC, practice, section quiz
- `arboriculture-operations/` — pruning, selection/planting, safety/climbing, risk/support, section quiz
- `urban-forestry/` — urban forest management, construction, section quiz
- `_data/domains.yml` — navigation and homepage cards
- `_layouts/`, `_includes/`, `assets/`, `images/` — shared site presentation

Add or reorder lesson links in `_data/domains.yml`; navigation and homepage cards update from that file.
